# Glimmering Glow

Build a high-end animated e-commerce landing experience for a luxury cosmetics brand. Use a modern luxury minimalist look in blush pink, warm cream, champagne-gold accents and deep slate text. Implement the requested sticky glass/blur navigation, cinematic hero with smooth visual motion, 4-benefit hover grid, responsive bestseller cards with image-hover swap, ratings, wishlist and Quick Add toast behavior, animated category filtering, and testimonial carousel. Make all interaction genuinely work: real-time product search, cart drawer with quantities/totals and checkout-preview modal, and a multi-step skin quiz modal that recommends a bundle. Ensure every nav/button has meaningful behavior and the UI is mobile-first, polished, and accessible. Use Lucide icons and motion animations; include product imagery through suitable remote/generative assets. Enable Lovable Cloud only if it is actually needed; stateful prototype behavior can remain client-side.
